# SETU SWFW_5S_02: Demonstration Materials

This directory contains the demonstration assets for course project **SETU SWFW_5S_02** (Local Multi-Region Highly Available Data Platform with Automated Disaster Recovery, Chaos Engineering, and GitOps):

1. **`DEMO_SCRIPT.md`**:
   The full screen recording and live evaluation script detailing the narration, terminal actions, expected outputs, timings, and safety checklist for the 10-step self-healing demonstration (`make demo`).

2. **`demo-run.log`**:
   An immutable terminal execution log captured with `tee` during a live, end-to-end execution of `make demo` on Ubuntu Linux (WSL2), concluding with exit code 0.

3. **Demonstration Status**:
   - Live demonstration will be conducted in person during the Zoho Campus Offline Review (November 2026).
   - If an offline video recording (`demo_video.mp4`) is added to this directory prior to final distribution and keeps the archive size below 15 MB, it will be packaged directly within the submission archive.
   - For offline evaluation without a video file, refer to `demo-run.log` and the step-by-step walkthrough in `DEMO_SCRIPT.md`.
